# Color Picker

웹페이지의 색상을 픽셀 단위로 선택하고 HEX 코드로 복사하는 Chromium 확장 프로그램입니다.

## 설치

1. 이 저장소를 내려받습니다.
2. Chrome 또는 Comet에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택하고 `manifest.json`이 있는 폴더를 고릅니다.
4. 일반 웹페이지에서 확장 프로그램 아이콘을 눌러 사용합니다.

## 사용 방법

- **확장 프로그램 아이콘**을 누르거나 `Option(Alt) + Shift + C`를 눌러 현재 페이지에서 확대 화면을 보며 원하는 픽셀을 클릭하면 HEX 코드가 바로 복사됩니다. `Esc`로 취소할 수 있습니다.
- 단축키가 작동하지 않거나 다른 키로 바꾸려면 `chrome://extensions/shortcuts`에서 확인합니다.
- 브라우저 내부 페이지나 확장 프로그램 스토어 등 일부 보호된 페이지에서는 작동하지 않습니다.

## 개인정보와 권한

선택한 색상은 기록하지 않습니다. 외부 서버, 계정, 분석 도구는 사용하지 않습니다. 현재 탭 접근과 스크립트 실행 권한은 사용자가 색상 선택을 요청했을 때 표시 중인 화면을 캡처하고 선택 화면을 띄우는 데 쓰입니다. 캡처 이미지는 선택 화면에서만 임시로 사용되며 파일에 저장되지 않습니다. 클립보드 권한은 선택한 HEX 코드를 복사할 때 사용합니다.
